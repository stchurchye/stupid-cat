# Windows production deps for the GTX 1060 (Pascal, compute capability 6.1 / sm_61).
#
# Install with the CUDA 12.1 wheel index — these are the last torch/torchvision
# wheels that comfortably ship sm_61 kernels. Newer torch (>=2.6, cu124/cu126+)
# has begun dropping Pascal, which fails at runtime with:
#     "no kernel image is available for execution on the device".
# Pins are exact so a reinstall months from now can't silently pull a wheel that
# no longer supports the 1060. The startup self-check (python -m stupid_cat ...)
# logs torch.version.cuda + device capability and warns loudly on a mismatch.
#
# Usage:
#   pip install -r requirements-win-cuda.txt
#   pip install -e .            # (install_win.ps1 does both)

--extra-index-url https://download.pytorch.org/whl/cu121
